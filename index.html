1What's Happening in This Lecture

Here's a sneak peek at everything we cover today, and why each one is worth showing up for.

TopicWhat It Covers
Shallow vs Deep CopyNot every "copy" is a copy. You'll find out what = really does to an array, why a slice is a view that shares data with the original, and which operations give you an independent copy instead. You'll also see when .copy() is enough and when you need copy.deepcopy(). This is the habit that keeps an official dataset safe while you experiment on it.
Array StackingJoin arrays into one: np.vstack() adds rows, np.hstack() adds columns, and np.concatenate() lets you choose the axis. You'll assemble a master table from separate files and add a totals column and a summary row. Think UNION ALL, with one important difference from a SQL JOIN that you'll see in class.
Array SplittingThe reverse of stacking: cut one array into pieces with np.vsplit(), np.hsplit() and np.split(), by rows, by columns or at positions you choose. For pieces that don't divide evenly, np.array_split() handles it. You'll also check whether the pieces are linked to the original, which connects back to views.
Matrix MultiplicationElement-wise * multiplies position by position; matrix multiplication with @ combines each row of one array with each column of another, multiplying matching pairs and adding them up. You'll use it to compute weighted scores, run several weighting schemes in one operation, and learn the shape rule (m, k) @ (k, n) → (m, n). You'll also compare np.dot, np.matmul and @, and see how much the choice of weights can matter.
NumPy Array vs Pandas DataFrameNumPy stores numbers by position; Pandas stores a labelled table with one type per column. You'll put the same data in both, see what happens when text and numbers share a NumPy array, and learn the everyday workflow: load and label with Pandas, pull the numbers out with .to_numpy() for the maths, and write the result back as a column.

2Real-World Use Cases

  • Shallow vs Deep Copy: A pricing analyst tests a 10% price increase on a copy of the price table, so the live table feeding the sales dashboard stays exactly as it was.
  • Array Stacking: A regional analyst combines the North and South sales files (same columns) into one national table, then adds a totals column and a company-average row before sending it up.
  • Array Splitting: An operations lead cuts the national table into one sheet per region for each regional manager, and sends a large customer file to a vendor in batches that don't need to be equal.
  • Matrix Multiplication: An HR analyst computes every employee's appraisal score from ratings on four criteria with 40/30/20/10 weights, and runs a second weighting scheme in the same operation to check whether anyone's rating band changes.
  • NumPy Array vs Pandas DataFrame: A demand analyst loads a sales CSV with Pandas, pulls the numeric columns into NumPy for a weighted forecast, and writes the forecast back as a column for the region-wise report.

TopicWhat to Recall
Boolean Masking & Fancy Indexingresults[results < 35] selects by condition; results[[1, 3, 6]] selects by position. Today you'll find out which of these give you a copy and which don't.
Aggregates with axissum(axis=1) gives one value per student (row); mean(axis=0) gives one per subject (column). You'll use both to build a totals column and an average row.
Broadcasting & Column Shapes(8, 3) * (3,) applies one value per column. A flat (8,) array needs reshape(8, 1) to act as a column. The same idea comes back when you join arrays.
Reading ShapesCheck .shape before combining two arrays. Stacking and matrix multiplication both have rules about which sizes must match, and the error messages point to the size that doesn't.
Element-wise Operations* on arrays works position by position. Today it meets a second kind of multiplication, and knowing exactly what * does is what makes the contrast clear.
